# Histórico de versões

> A documentação pública do repositório foi reorganizada em 22/10/2026 para apresentar apenas o plugin. Essa alteração não muda o artefato estável 1.4.8.

## 1.4.8 — 22/10/2026

- Adicionado atalho para anexar a logo e criar CSS com suas cores.
- Incluído fluxo de análise da paleta, com distinção entre cores extraídas, aproximadas e derivadas.
- Mantidos os destinos painel, login ou ambos, com os ajustes anteriores do login.
- Publicação inicial deste repositório com documentação em português brasileiro, pacote completo e soma SHA-256.

## 1.4.7 — 22/10/2026

- Adicionado o atalho de criação de CSS para a tela de login.
- Preservadas as três sugestões anteriores e os modelos existentes.

## Base 1.4.6

- Tema do painel com cores, tipografia e acabamento.
- Login em duas colunas, versão móvel, modos claro/escuro, logo menor e frase opcional.
- Link real de recuperação abaixo da senha, alinhado à direita.

As notas da base resumem os recursos presentes no pacote recebido; não reconstituem todas as alterações anteriores.
