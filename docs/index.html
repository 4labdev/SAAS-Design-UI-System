Escolha por onde começar.

Personalize uma tela ou combine painel e login. O CSS é preparado de acordo com a estrutura compatível da sua plataforma.

01 / PAINEL

Uma interface com a sua cara.

Aplique a cor principal, escolha a tipografia e defina o acabamento dos elementos do tema.

  • Fonte do sistema, Inter, Roboto ou Open Sans
  • Acabamento essencial ou refinado
  • Ajustes de contraste nos botões
02 / LOGIN

Uma entrada bem apresentada.

Área da marca e formulário lado a lado no desktop, com adaptação para uma coluna no celular.

  • Logo menor e frase opcional
  • Paletas para claro e escuro
  • Recuperação abaixo da senha, à direita
03 / SUA LOGO

Comece pela sua identidade.

Anexe a logo na conversa e peça uma paleta para o painel, o login ou os dois.

  • Cores identificadas e tons derivados
  • HEX aproximados quando a análise for visual
  • Preservação do arquivo original da logo

Do download à geração de CSS

Um caminho simples.
Você no controle.

O pacote reúne uma skill, um gerador Python e referências. Ele cria o CSS; você escolhe quando aplicá-lo.

Consultar o guia de uso ↗

Baixe e extraia o pacote

Use o ZIP completo da versão 1.4.8, com skill, gerador e referências técnicas.

Escolha como usar

Carregue a skill em um ambiente compatível, seguindo seu mecanismo de instalação. Como alternativa, execute o gerador local com Python 3. Anexar o ZIP a uma conversa não instala o plugin permanentemente.

Conte como é a sua marca

Informe cor, fonte e a tela desejada — ou anexe sua logo na conversa. Use um dos exemplos abaixo como ponto de partida.

Revise o CSS gerado

Confira a paleta, a tipografia, o escopo solicitado e as orientações de compatibilidade. O plugin entrega CSS; não altera sua aplicação automaticamente.

Comece com um pedido

Copie. Personalize. Crie.

Leve um destes exemplos para a conversa com a skill disponível.

Tema do painel

Crie o CSS do meu painel com a cor #087F5B, fonte Inter e acabamento refinado.

Tela de login

Personalize somente o login em duas colunas. Use verde #087F5B e a frase “Sua operação em um só lugar”. Mantenha a fonte atual e os modos claro e escuro.

A partir da logo

Extraia as cores da logo que anexei e crie o CSS para o painel e o login. Mostre a paleta e diferencie as cores da marca dos tons ajustados para contraste.

Antes de começar

Respostas diretas.

Preciso saber programar?

O fluxo conversacional orienta a geração do CSS. Em plataformas com HTML diferente da base documentada, a adaptação dos seletores pode exigir conhecimento técnico.

O pacote instala diretamente no ChatGPT?

Não há garantia de importação por ZIP em qualquer conta. Use o mecanismo de plugins ou skills disponível no seu ambiente. Consulte o guia de uso para os formatos de execução suportados.

Posso usar no Claude?

O núcleo é uma skill com instruções, scripts e referências que pode ser adaptada. Esta versão ainda não foi validada no Claude e o ZIP completo não é apresentado como um instalador pronto para ele.

A logo é aplicada automaticamente?

Não. Anexar a logo permite analisar suas cores. O arquivo configurado na plataforma é preservado; sua substituição é uma etapa separada.

Funciona em qualquer SaaS?

Os perfis atendem às estruturas documentadas. Para outra plataforma ou versão, pode ser necessário fornecer o HTML renderizado e sanitizado da tela, sem credenciais ou dados pessoais.

Como desfaço uma alteração?

Restaure o CSS que você salvou antes da aplicação e atualize a página com Ctrl + Shift + R. Confira as telas e os controles de acesso.

Por que a cor do botão pode mudar?

O gerador pode escurecer a cor para melhorar o contraste com o texto branco. A entrega distingue a cor solicitada da aplicada. Isso não representa uma auditoria de acessibilidade de toda a plataforma.
